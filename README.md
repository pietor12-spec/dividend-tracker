# Dividend Tracker

App web para llevar el control de los cobros de dividendos: resumen, cobros, empresas, peso, calendario, previsión y evolución por año.

- **Úsala desde el navegador**: abre el enlace de GitHub Pages del repositorio.
- **Instálala como app**: en el móvil, menú del navegador → *Añadir a pantalla de inicio* / *Instalar app*; en el ordenador, icono de instalar en la barra de direcciones (Chrome/Edge).
- **Tus datos** se guardan en el navegador de cada dispositivo (almacenamiento local) y la app funciona sin conexión.
- Para pasar datos de un dispositivo a otro: *Ajustes → Copiar mis datos* en uno y *Importar* en el otro.
